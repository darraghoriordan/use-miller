# Miller Dev Shell

Miller Dev Shell is a reproducible developer-machine setup for macOS and Windows through WSL.
It replaces a long checklist of manual installations and dotfile changes with inspectable,
rerunnable shell scripts.

## What it includes

- Package installation for common developer tools
- A consistent Zsh environment across macOS and Windows WSL
- Git, npm, shell, terminal, and global ignore configuration
- VS Code settings and common development extensions
- Developer fonts and a configured shell prompt
- Faster, syntax-aware command-line tools
- Optional repository cloning during machine setup
- Source access so the setup can be audited and adapted

## Best suited to

Dev Shell is for developers who want a new computer, replacement laptop, or second operating
system to feel familiar without manually reproducing years of accumulated setup.
